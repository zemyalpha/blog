# 합성 데이터로 LLM 사전학습을 5~10배 빠르게: 30% 비율과 모델 붕괴의 진실

합성 데이터(Synthetic Data)는 이미 LLM 파인튜닝과 정렬 단계에서 널리 쓰인다. 하지만 **사전학습(Pre-training) 단계**에서 합성 데이터가 어떤 효과를 내는지, 그리고 어느 비율까지 안전한지는 최근까지도 제대로 검증되지 않은 영역이었다. 대부분의 실무자가 "합성 데이터를 쓰면 모델 붕괴(Model Collapse)가 온다"는 막연한 우려만 갖고 있을 뿐이다.

2025년 말 Meta FAIR와 버지니아 공대, Cerebras가 공동으로 발표한 대규모 실증 연구가 이 질문에 처음으로 체계적인 답을 내놓았다. 이 글은 그 연구의 핵심 발견과, 모델 붕괴를 피하면서 합성 데이터를 사전학습에 활용하는 실전 결정 프레임워크를 정리한다.

## 합성 데이터가 사전학습에서 풀어야 할 문제

고품질 자연어 데이터는 유한하다. 고품질 학습 데이터 부족은 LLM 스케일링의 가장 현실적인 병목이 되었고, 합성 데이터는 이를 우회할 잠재적 경로로 주목받는다. 합성 데이터는 정의상 기존 모델이나 자동화 파이프라인이 생성한 텍스트를 의미하며, 자연 데이터를 증강하거나 궁극적으로 대체할 수 있다.

그러나 합성 데이터의 역할은 사용 단계에 따라 크게 다르다. 파인튜닝·정렬 단계에서는 목표가 명확하고 자연 데이터가 희소해서 합성 데이터의 효용이 비교적 잘 확립되어 있다. 반면 사전학습 단계에서는 그 영향과 조건이 오랫동안 불분명했다. Nadas 등(2025)의 서베이(arXiv:2503.14023, IEEE Access 2025)는 합성 데이터 생성 기법으로 프롬프트 기반 생성, 검색 증강 파이프라인, 반복적 자기 정제를 꼽으며, 동시에 사실 부정확, 분포의 비현실성, 편향 증폭이라는 과제를 지적한다.

## Meta FAIR 실험: 1,000개 모델으로 밝힌 네 가지 발견

Kang 등의 연구(arXiv:2510.01631, 2025년 10월)는 가장 규모가 큰 사전학습 합성 데이터 실증 연험 중 하나다. 3B 파라미터까지 모델 1,000개 이상을, 최대 200B 토큰 데이터셋으로, 10만 GPU 시간 이상을 사용해 학습하고 스케일링 법칙으로 결과를 비교했다. 핵심 발견은 네 가지다.

**첫째, 적절한 비율의 합성 데이터는 사전학습 수렴을 크게 가속한다.** 자연 웹 텍스트 2/3에 재구성(rephrased) 합성 데이터 1/3을 섞으면, 같은 검증 손실(validation loss)에 도달하는 속도가 **5~10배** 빨라졌다. 다만 이 효과는 데이터 예산이 충분히 클 때 나타난다.

**둘째, 합성 데이터 단독 사용은 효과가 없거나 오히려 해롭다.** 재구성 합성 데이터만으로 학습하면 자연 웹 텍스트보다 빠르지 않았고, 교과서 스타일(textbook-style) 합성 데이터만으로 학습하면 검증 손실이 눈에 띄게 높았다. 혼합이 핵심이지 대체가 아니다.

**셋째, '좋은' 비율은 조건에 따라 다르지만 하나의 경향이 있다.** 재구성 합성 데이터의 적정 비율은 모델 크기와 데이터 예산에 따라 달라지지만, 실험 범위에서 **약 30%** 로 수렴했다.

**넷째, 더 큰 생성 모델이 반드시 더 좋은 합성 데이터를 만들지는 않는다.** 직관과 달리, 사전학습 데이터 생성에는 약 8B 파라미터급 모델이면 충분했고, 그 이상의 큰 모델이 유의미하게 더 나은 데이터를 만든다는 증거는 없었다. 비용 효율 관점에서 중요한 시사점이다.

이 결과는 모델 붕괴 논쟁에도 혼합된 증거를 던진다. 재구성 합성 데이터로 단일 라운드 학습할 때는 관측 가능한 스케일에서 성능 저하가 나타나지 않았지만, 순수 생성형 교과서 스타일 합성 데이터 혼합물에서는 모델 붕괴가 예측한 패턴이 나타났다. **합성 데이터의 종류가 붕괴 위험을 좌우한다는 것**이 핵심이다.

## 모델 붕괴: 피해야 할 위협인가, 관리 가능한 리스크인가

모델 붕괴는 연속된 세대의 모델이 이전 세대 출력으로 학습하면서 원본 데이터 분포의 꼬리를 점점 잃고, 결국 거의 단일점(delta-function)에 가까운 출력으로 수렴하는 퇴행 과정이다. Shumailov 등이 2024년 7월 *Nature*에 발표한 연구(DOI:10.1038/s41586-024-07566-y)는 모델 붕괴가 VAE, 가우시안 혼합 모델, LLM을 가리지 않고 보편적인 현상임을 보였다. 이 논문의 핵심 경고는 "모델 생성 콘텐츠의 무차별적 사용이 결과 모델에 돌이킬 수 없는 결함을 초래한다"는 것이다. 중요한 단어는 **무차별적(indiscriminate)**이다.

같은 해 Gerstgrasser 등(2024)은 분석적으로, 합성 데이터가 실제 데이터를 **대체**할 때가 아니라 **축적**할 때 테스트 오차의 상한이 유한하게 유지된다고 증명했다. 즉 모델 붕괴의 해법은 합성 데이터를 피하는 것이 아니라, 실제 데이터를 함께 유지하는 것이다. "축적하라, 대체하지 마라(Accumulate, don't replace)"가 실천적 원칙이다.

실제 사례로 이 원칙이 어떻게 작동하는지 볼 수 있다. Microsoft의 phi-1(1.3B 파라미터)은 6B 토큰의 웹 데이터에 GPT-3.5로 생성한 약 1B 토큰의 "교과서 품질" 합성 데이터를 더해 학습해, HumanEval pass@1 50.6%, MBPP 55.5%를 기록하며 자기보다 10배 큰 모델과 맞먹는 코딩 성능을 냈다(arXiv:2306.11644). 반면 OPT-125m을 순수 합성 데이터로 5 에포크 자기 학습한 실험에서는 실제 데이터를 전혀 보존하지 않아 퍼플렉서티가 20~28포인트 악화했다. 같은 합성 데이터라도 운용 방식에 따라 결과가 정반대다.

## 실전 결정 프레임워크

위 연구들을 종합하면, 사전학습에 합성 데이터를 도입할 때 다음 기준을 적용할 수 있다.

**1. 생성 방식을 목적에 맞게 선택하라.** 재구성(rephrasing) 기반 합성 데이터는 자연 데이터와 분포가 가깝고 붕괴 위험이 낮아 사전학습 혼합에 적합하다. 순수 생성형 교과서 데이터는 도메인 지식 밀도가 높지만 단독·장기 사용 시 붕괴 패턴이 나타날 수 있으므로 자연 데이터와 반드시 섞어 써야 한다.

**2. 혼합 비율을 30% 근처에서 시작하라.** Meta FAIR 연구의 경험적 수렴점이 약 30%다. 모델 크기와 데이터 예산에 따라 미세 조정하되, 합성 데이터 비율을 무작정 높이는 것은 검증되지 않은 도박이다.

**3. 생성기는 8B급이면 충분하다.** 더 큰 생성 모델이 더 나은 데이터를 만든다는 보장이 없으므로, 비용 효율을 위해 과도하게 큰 모델을 생성기로 쓸 필요가 없다.

**4. 실제 데이터를 항상 함께 유지하라.** 모델 붕괴 방지의 가장 단순하고 강력한 원칙이다. 합성 데이터를 "더하는" 용도로 쓰고, 자연 데이터를 "빼지" 마라.

**5. 품질 필터링을 생략하지 마라.** 서베이가 지적한 대로 합성 데이터의 사실 부정확과 편향 증폭은 실제 위험이다. 생성 후 중복 제거, 품질 점수 기반 필터링, 도메인별 검증 파이프라인을 거쳐야 한다.

참고할 만한 공개 데이터셋으로 Hugging Face의 Cosmopedia가 있다. Phi-1.5의 학습 데이터를 재현하기 위해 Mixtral-8x7B-Instruct로 생성한 대규모 합성 코퍼스로, 수십억 토큰 규모로 알려져 있다. Hugging Face팀은 주제뿐 아니라 청중(audience)과 형식(format)이라는 추가 축을 변화시켜 분포의 다양성을 넓히는 전략을 사용했다. 코드, 데이터셋, 학습된 1B 모델(cosmo-1b)까지 전부 공개한 점이 특징이다.

## 결론: 핵심 요약

- **사전학습에서 합성 데이터는 효과적이다**, 단 자연 데이터와 섞어 쓸 때. 재구성 합성 데이터 1/3 + 자연 데이터 2/3 조합은 같은 검증 손실 도달을 5~10배 가속했다.
- **적정 비율은 약 30%**. 재구성 합성 데이터 기준, 모델 크기와 예산에 따라 미세 조정.
- **합성 데이터 단독은 위험**. 특히 순수 생성형 교과서 데이터는 모델 붕괴 패턴을 보였다.
- **생성기는 8B급이면 충분**. 더 큰 모델이 유의미하게 더 나은 데이터를 만든다는 증거는 없다.
- **"축적하라, 대체하지 마라"**. 모델 붕괴 방지의 핵심 원칙. 실제 데이터를 함께 유지하면 오차 상한이 유한하게 유지된다.

당장 시도해볼 첫 단계는 간단하다. 기존 자연 데이터 코퍼스에 재구성 방식으로 생성한 합성 데이터를 약 30% 비율로 섞고, 동일한 검증 손실 곡선을 비교하는 소규모 실험을 돌려보는 것이다. 검증 손실이 더 빨리 수렴하는지, 다운스트림 태스크 성능이 유지되는지 확인하면, 더 큰 규모로 확장할 근거를 얻을 수 있다.
